# Hermes

> A personal AI agent that lives where you already chat.

## What is Hermes?

**Hermes** is an autonomous AI assistant that connects a powerful language model to real tools and real messaging platforms. Instead of being locked inside a single app, Hermes meets you where you already are — Telegram, Discord, Slack, SMS, and more — and acts as a capable, always-available agent that can actually *do* things, not just talk about them.

It bridges the gap between a conversational AI and a true digital assistant by giving the model access to a terminal, a filesystem, the web, and a growing ecosystem of skills and integrations.

## Key Features

- **Multi-platform messaging** — Talk to Hermes from Telegram, Discord, Slack, Signal, Matrix, SMS, and other channels.
- **Real tool access** — Runs shell commands, reads and writes files, searches and browses the web, and manages code repositories.
- **Skills system** — Reusable, procedural knowledge modules that teach Hermes specialized workflows (GitHub management, document creation, data science, smart home control, and many more).
- **Persistent memory** — Remembers your preferences, environment details, and conventions across sessions so you never have to repeat yourself.
- **Scheduled jobs** — Cron-style automation for recurring tasks like daily briefings, monitoring, and reports.
- **Subagents & delegation** — Spawns parallel worker agents to handle complex, multi-part tasks efficiently.
- **Voice & media** — Text-to-speech, image generation, and native media delivery on supported platforms.

## How It Works

1. You send a message from any connected platform.
2. Hermes interprets your intent and selects the right tools and skills.
3. It executes the task — running commands, calling APIs, editing files, or researching the web.
4. It reports back to you in the same conversation, with results, files, or media attached.

## Use Cases

- Automating development workflows (creating repos, opening PRs, reviewing code)
- Research and summarization
- Managing notes, documents, and productivity tools
- Home automation and smart device control
- Scheduled monitoring and reporting
- Acting as a general-purpose personal assistant
